# Віртуальні лабораторії

Ресурс створено для уроків хімії та інших природничих наук: учні можуть безпечно проводити досліди у віртуальній лабораторії, спостерігати за перебігом реакцій і перевіряти свої висновки там, де справжні реактиви недоступні або небезпечні.
