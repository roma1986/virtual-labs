# Віртуальні лабораторії

Інтерактивні симулятори для уроків природничих наук. Учні проводять досліди без реактивів і без ризику: зливають розчини, спостерігають за реакціями й перевіряють рівняння.

## Симулятори

| Симулятор | Предмет | Клас | Адреса |
|---|---|---|---|
| Реакції йонного обміну між електролітами у водних розчинах | Хімія | 9 | `chemistry/ion-exchange/` |

Симулятор «Реакції йонного обміну» створено до навчального дослідження 9 з підручника «Хімія, 9 клас» (О. В. Григорович, с. 98–99).

## Як опублікувати на GitHub Pages

1. Створіть репозиторій `virtual-labs` і завантажте в нього всі файли з архіву, зберігаючи папки.
2. Відкрийте **Settings → Pages**.
3. У розділі **Build and deployment** оберіть **Deploy from a branch**, гілку `main` і папку `/ (root)`, натисніть **Save**.
4. За кілька хвилин сайт відкриється за адресою `https://<ваш-логін>.github.io/virtual-labs/`.

QR-код у симуляторі автоматично веде на адресу симулятора на GitHub Pages.

## Як додати новий симулятор

1. Створіть папку `предмет/тема/` і покладіть у неї `index.html`, наприклад `physics/ohms-law/index.html`.
2. У файлі `index.html` у корені допишіть новий об’єкт у список `SIMS` і вкажіть `url: 'physics/ohms-law/'`.
